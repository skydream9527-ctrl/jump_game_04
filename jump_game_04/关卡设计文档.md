# 天穹跃迁 — 全 110 关详细设计文档

> 版本：v1.0
> 更新日期：2026-05-19
> 本文档定义每一关的目标距离、平台布局、敌人配置、碎片位置、道具策略、通关要点。

---

## 通用参数说明

| 参数 | 含义 |
|------|------|
| 目标距离 | 到达该距离即通关（单位：游戏像素） |
| 平台间距系数 | 越大间距越宽，难度越高 |
| 速度系数 | 越大滚动越快 |
| 碎片 | 每关固定 3 个，用于评级和货币 |
| 评级 | ★☆☆ = 通关 / ★★☆ = 收集 2 碎片 / ★★★ = 全碎片 + 通关 |
| 道具 | 护盾、磁铁、缓时、强化靴，每平台 12% 概率刷新 |
| 武器 | 手枪/散弹/激光/机枪/火球，每平台 10% 概率刷新 |

### 关卡难度标尺

| 符号 | 含义 |
|------|------|
| ⚔ | 有敌人出现 |
| 🧊 | 有冰面平台 |
| 🔥 | 有融化平台 |
| 👻 | 有隐形平台 |
| 💎 | 碎片位置刁钻 |
| 🛡 | 推荐携带护盾 |
| ⭐ | Boss 关 |

**章节主题：** 锈蚀废墟城市，倒塌高楼残骸构成平台

| 项目 | 值 |
|------|-----|
| 目标距离 | 3800 |
| 平台间距系数 | 1.0 |
| 速度系数 | 1.0 |
| 难度 | ★☆☆☆☆ |

**关卡特点：**

- 学习跳跃节奏：点击屏幕或按空格跳起

- 本关不鼓励使用二段跳，仅需基础跳跃即可通关

### 1-10　「钢铁巨像」⭐

| 项目 | 值 |
|------|-----|
| 目标距离 | 11000（前 85% 为跑酷段，最后触发 Boss） |
| 平台间距系数 | 1.20 |
| 速度系数 | 1.03 |
| 难度 | ★★★★☆ |

**关卡特点：**
- 前 85% 为跑酷段，难度与 1-9 相当
- 到达 85% 距离后触发 Boss 战
- Boss 战在固定场景中进行，平台自动生成

**Boss：废墟守卫**

| 属性 | 值 |
|------|-----|
| HP | 30 |
| 体型 | 60×60 |
| 移动速度 | 1.0 |
| 攻击模式 1 | 冲锋（0.8 秒，冷却 2 秒） |
| 攻击模式 2 | 砸地（0.6 秒，冷却 3 秒） |
| 阶段变化 | HP ≤ 50% 时进入狂暴，速度 ×1.5 |

**Boss 战流程：**
1. Boss 出现在屏幕右侧，缓慢向玩家靠近
2. Boss 执行「冲锋」：快速冲向玩家位置，然后返回
3. Boss 执行「砸地」：跳起后砸下，产生冲击波子弹（8 方向散射）
4. 玩家需要在 Boss 攻击间隙跳到 Boss 头顶踩踏
5. 每次踩踏扣 1 HP，Boss 被弹开并短暂无敌
6. HP ≤ 50% 后 Boss 进入狂暴：攻击速度加快，冲锋距离更远

**碎片位置：**
1. 跑酷段第 3 个平台上方
2. 跑酷段第 7 个平台上方
3. Boss 战场景中，Boss 身后高台上（击败 Boss 后才能安全拾取）

**通关要点：**
- Boss 战中保持在平台高处，等 Boss 攻击完再跳下踩头
- 冲锋攻击时向旁边平台跳跃闪避
- 砸地攻击时跳到高台躲避冲击波
- 狂暴阶段攻击间隔更短，需要更快反应
- 推荐携带护盾进入 Boss 战
