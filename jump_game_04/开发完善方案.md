## 一、项目现状分析

### 1.1 项目定位

**天穹跃迁** 是一款横版卷轴跑酷动作游戏。世界观设定于 2187 年，玩家扮演「跃迁者」穿越 10 颗星球，收集星核碎片、对抗星际威胁，拯救崩塌中的天穹城市群。

游戏具有 **双端并行** 的特点：
- **Android 原生版**（Kotlin + Jetpack Compose）：核心跑酷体验已实现
- **Web 版**（React 19 + TypeScript + Phaser 3）：功能最完整，含战斗/Boss/忍术等系统

## 二、核心理念与设计哲学

### 2.1 游戏精神

| 维度 | 定位 |
|------|------|
| 核心体验 | 「那一跳」的精准感 + 速度感 + 流动感 |
| 情感目标 | 恐惧星球环境 → 征服难关 → 英雄式满足感 |
| 内容深度 | 表面是跑酷，内藏战斗/收集/成就/剧情多层次 |
| 长线设计 | 10 颗各具特色星球 × 不同机制 = 永不重样 |

### 2.2 三大设计支柱

#### 支柱一：物理手感极致打磨
- 跳跃弧线必须「手感」好，弧线需要经过反复数值调参
- 落地反馈（震屏 + 粒子）要有重量感
- 不同角色的物理参数差异必须真实可感知

#### 支柱二：环境叙事与视觉震撼
- 每颗星球不只是换颜色，而是有独特的**平台机制 + 视觉语言**
- 月球的低重力飘浮感、火焰星的融化倒计时、暗物质领域的黑暗探索
- 视差背景 + 粒子特效 + 环境音效 = 完整的星球沉浸感

#### 支柱三：角色个性鲜明
- 4 个角色不是皮肤，是真正不同的游戏体验
- 疾风的速度感 vs 艾珂的跳跃高度 vs 零号的精准着陆 = 玩家选择

### 2.3 核心游戏循环

```
【单局循环（5-8分钟）】
进入关卡 → 跑酷跳跃 → 收集碎片 → [Boss关] → 结算评级
    ↓
【中期循环（1-3天）】
积累碎片 → 解锁新角色 → 探索新关卡 → 获得更高评级
    ↓
【长期循环（1-4周）】
收集全部★★★ → 解锁全成就 → 冲击排行榜 → 解锁故事结局
```

### 6.3 特殊平台机制完善

#### 6.3.1 冰面平台（第 5 章）

```typescript
class IcePlatform extends Platform {
  private slideVelocity = 0
  private readonly SLIDE_FRICTION = 0.92  // 滑行衰减系数
  private readonly MAX_SLIDE = 5          // 最大滑速
  
  onPlayerLand(player: Player) {
    // 落地时继承玩家水平速度的 60% 作为滑行速度
    this.slideVelocity = player.velocityX * 0.6
  }
  
  update(player: Player) {
    if (this.slideVelocity !== 0) {
      player.x += this.slideVelocity
      this.slideVelocity *= this.SLIDE_FRICTION
      if (Math.abs(this.slideVelocity) < 0.1) this.slideVelocity = 0
    }
  }
}
```

#### 6.3.2 融化平台（第 6 章）

```typescript
class MeltingPlatform extends Platform {
  private meltTimer = 0
  private readonly MELT_DURATION = 3.0  // 3秒后消失
  private isMelting = false
  
  onPlayerLand() {
    this.isMelting = true
  }
  
  update(delta: number) {
    if (this.isMelting) {
      this.meltTimer += delta
      const meltProgress = this.meltTimer / this.MELT_DURATION
      
      // 视觉反馈：颜色从暗红 → 橙色 → 消失
      this.tint = Phaser.Display.Color.Interpolate.ColorWithColor(
        { r: 0x8A, g: 0x40, b: 0x20 },  // 起始：暗红
        { r: 0xFF, g: 0x40, b: 0x00 },  // 结束：岩浆橙
        100, meltProgress * 100
      )
      
      if (meltProgress >= 1) this.destroy()
    }
  }
}
```

#### 6.3.3 隐形平台（第 9 章）

```typescript
class InvisiblePlatform extends Platform {
  private readonly REVEAL_RANGE = 100  // 玩家接近 100px 时显示
  
  update(playerX: number, playerY: number) {
    const dist = Phaser.Math.Distance.Between(
      this.x, this.y, playerX, playerY
    )
    // 距离越近越不透明
    this.alpha = dist < this.REVEAL_RANGE 
      ? (1 - dist / this.REVEAL_RANGE) * 0.9 + 0.1
      : 0.0
  }
}
```

    }

// 当前：GameEngine 承担所有逻辑，过于庞大
// 目标：ECS 架构，职责分离

// 组件定义
data class TransformComponent(var x: Float, var y: Float)
data class PhysicsComponent(var vx: Float, var vy: Float, val gravity: Float)
data class RenderComponent(val color: Int, val width: Float, val height: Float)
data class CollisionComponent(val bounds: RectF)

// 系统定义
class PhysicsSystem(private val entities: List<Entity>) {
    fun update() {
        entities.forEach { entity ->
            val physics = entity.getComponent<PhysicsComponent>() ?: return@forEach
            val transform = entity.getComponent<TransformComponent>() ?: return@forEach
            
            physics.vy += physics.gravity
            transform.x += physics.vx
            transform.y += physics.vy
        }
    }
}
