## 关卡类型

每个章节包含以下类型的关卡：

- **第1关**：教学关卡 - 学习新机制
- **第2-4关**：普通关卡 - 逐步提升难度
- **第5关**：小Boss关卡 - 遭遇章节小Boss
- **第6-9关**：进阶关卡 - 高难度挑战
- **第10关**：Boss关卡 - 击败章节大Boss

## 设计文件内容

每个关卡设计文件包含以下内容：

1. **关卡信息** - 基本参数（距离、速度、难度等）
2. **关卡特点** - 关卡类型和特殊说明
3. **特殊机制** - 章节特有机制
4. **可选角色** - 推荐角色和选择建议
5. **推荐武器** - 适合的武器配置
6. **推荐道具** - 建议携带的道具
7. **敌人列表** - 出现的敌人类型
8. **通关技巧** - 游戏策略建议
9. **星核碎片收集** - 收集位置提示
