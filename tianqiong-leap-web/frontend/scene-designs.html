荒废地球教学关 · 废墟荒原
CH.1 — RUINED EARTH
背景层次（7层）：天空灰蓝微光 + 5层云 → 远山3座暗灰剪影 → 中山3座 → 近山2座 → 建筑废墟断壁×2 + 塔楼 + 矮墙 + 断柱×2 → 地面死树×2 + 小河 + 碎石 + 杂草 → 前景细雨 + 风沙 + 飞鸟。
新增细节：断柱雕塑、枯树剪影、小河流淌、地面纹理层、飞鸟群、更多碎石。
参考：《空洞骑士》遗忘十字区废墟 × 《塞尔达》旷野之息海拉尔平原。

月球基地低重力 · 太空寂静
CH.2 — MOON BASE
背景层次（8层）：深空12颗闪烁星 + 双星云 + 远处2颗行星 → 地球云层+大陆纹理 → 月面5个陨石坑 → 基地穹顶+窗户灯光+天线红灯+太阳能板阵列 → 设备月球车+脚印+卫星。
新增细节：远处行星（橙色+蓝色）、卫星过境、窗户灯光渐变、更多陨石坑、脚印轨迹。
参考：《塞尔达》天空之城太空感 × 《空洞骑士》深邃巢穴绝对黑暗。

参考：《塞尔达》格鲁德沙漠炎热 × 《空洞骑士》泪水之城环境叙事。

水银星液态金属 · 银色镜面

背景层次（6层）：星云双色星云 → 金属柱4根+齿轮转动 → 管道3条+铆钉×4 → 液态金属3个池+5条液滴 → 地面镜面反射+光泽脉动。

参考：《塞尔达》时之笛水神殿液态质感 × 《空洞骑士》泪水之城金属氛围。

冰封星冰面滑动 · 极光之夜
CH.5 — ICE PLANET
背景层次（7层）：天空深蓝夜空 → 极光双层流动 → 冰柱6根参差 → 冰晶5块碎片+冰桥 → 地面冰原+霜冻层 → 生物冰狼剪影 → 前景大小混合雪花×10。
新增细节：双层极光、冰桥横跨、冰狼剪影、大小混合雪花、更多冰柱。
参考：《塞尔达》海布拉山脉雪景 × 《空洞骑士》水晶山峰寒冷感。

6
火焰星球熔岩流淌 · 火山喷发
CH.6 — FIRE PLANET
背景层次（7层）：天空暗红烟尘 → 火山活火山（喷发口发光+岩浆流）+ 休眠火山 → 远山2座焦黑剪影 → 熔岩河2条蜿蜒流淌 → 熔岩池3个脉动发光 → 地面焦岩+枯树+火焰精灵 → 前景火山灰飘落+热浪扭曲。
新增细节：活火山喷发口橙光、岩浆流淌动画、火焰精灵飘浮、焦树剪影、热浪扭曲效果、火山灰粒子。
参考：《塞尔达》死亡火山灼热 × 《空洞骑士》泪水之城余烬灰烬。
活火山喷发岩浆流淌火焰精灵焦树枯木热浪扭曲火山灰粒子熔岩池脉动休眠火山

雷电星球闪电风暴 · 电磁脉冲
CH.7 — THUNDER PLANET
背景层次（7层）：雷云3层叠压（最厚→薄） → 闪电3道劈落+电光扩散 → 远山3座暗蓝剪影 → 电塔2座高压塔+电弧连接 → 地面湿润反光+水洼 → 风暴暴雨斜落+风痕横扫 → 氛围电光闪烁照亮云层。
新增细节：高压电塔+电弧连接、水洼反射闪电、风痕横扫效果、3层云叠压、闪电照亮云层光晕。
参考：《塞尔达》雷之神殿电击 × 《空洞骑士》皇家水道暴雨。

丛林星藤蔓缠绕 · 萤火虫夜
CH.8 — JUNGLE PLANET
背景层次（8层）：夜空6星+弯月 → 树冠浓密遮天 → 巨树4棵参天大树+树冠 → 藤蔓5条垂挂+花朵×2 → 蘑菇3朵发光 → 地面草地层+杂草 → 生物8只萤火虫飘浮 → 氛围月光透过树冠缝隙。
新增细节：参天巨树剪影、藤蔓垂挂+花朵、发光蘑菇、萤火虫群、月光穿透效果、更多杂草。
参考：《塞尔达》科洛格森林神秘 × 《空洞骑士》绿色之路丛林。
参天巨树藤蔓垂挂发光蘑菇萤火虫群月光穿透浓密树冠弯月夜空花草丛生

暗物质领域虚空深渊 · 最终决战

背景层次（7层）：虚空深紫黑渐变+微弱脉动 → 传送门3环旋转+核心发光 → 远处星系3个螺旋剪影 → 暗物质触须3条蠕动 → 黑暗之眼3只若隐若现 → 裂缝3条空间裂隙 → 粒子暗物质粒子+浮空碎片。
新增细节：传送门旋转环、暗物质触须蠕动、黑暗之眼若隐若现、空间裂隙、远处星系、浮空碎片。
参考：《塞尔达》魔王城堡终极暗域 × 《空洞骑士》深渊无尽黑暗。
