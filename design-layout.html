二、问题分析

问题 1: 死亡判定失效

当前 (问题)
画布可见区域 (y: 0 ~ 393)
玩家
隐形缓冲区 (393 ~ 491) ← 问题!
掉到这里还没死
deathY = 491 才触发死亡

deathY = CANVAS_HEIGHT - CAMERA_SCROLL_Y = 393 - (-98) = 491
玩家掉出画面后还有 98px 才触发死亡，感觉判定"失效"

修复后 (方案)
画布可见区域 (y: 0 ~ 393)
玩家
deathY = 393 ← 掉出画面即死亡 ✓

deathY = CANVAS_HEIGHT = 393
玩家刚掉出画面就触发死亡，判定即时可靠

问题 2: 游戏页面不在画面中

当前 (问题)
.game-container (position: absolute; inset: 0)
Canvas 可能偏移 Scale.FIT + CENTER_BOTH 在某些窗口尺寸下不稳定

Phaser Scale.FIT 的 autoCenter 行为不可控
窗口尺寸变化或首次加载时 canvas 可能不在预期位置

修复后 (方案)
.game-container (display: flex; 居中)
Canvas 稳定居中 ✓

CSS flex 居中 + Phaser Scale.FIT
双重保障，canvas 始终在画面正中

三、修复方案详情

项目 当前值 修复值 说明
deathY CANVAS_HEIGHT - CAMERA_SCROLL_Y = 491 CANVAS_HEIGHT = 393 掉出可见画面即死亡
.game-container CSS position: absolute; inset: 0 display: flex; align/justify: center CSS 层面确保 canvas 居中
Phaser scale.mode Phaser.Scale.FIT Phaser.Scale.FIT (不变) 保持自适应缩放
Phaser scale.autoCenter CENTER_BOTH CENTER_BOTH (不变) Phaser 内部也居中
