## 🎮 Game Play

- Jump across moving platforms to reach higher scores.
- Avoid obstacles and timing traps.
- Smooth HTML5 Canvas animations and physics simulation.

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/skydream9527-ctrl/jump_game_04.git
   ```
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Safari, Firefox) or serve via Live Server.
